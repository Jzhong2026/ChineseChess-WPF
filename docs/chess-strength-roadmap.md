## 方案详析

### 🥇 MCTS sims 提升（立竿见影，零训练成本）

当前 MCTS 600 sims、每步 2.4s。改成 **2000-5000 sims**：

| sims | 每步耗时(估) | 棋力变化 |
|------|-------------|---------|
| 600 (当前) | 2.4s | Classic 16-0-4 |
| 2000 | ~6s | 搜索深 3.3 倍，可能赢 1-2 盘 |
| 5000 | ~12s | 搜索深 8 倍，可能赢 3-5 盘 |

✅ **零开发成本**，改 AiMatchRunner 里一个参数就行  
⚠️ 但用户体验会变卡（每步等 6-12 秒）

### 🥈 Factored Head (V8) 架构（性价比最高）

V7 的 8100 维 FC 是参数黑洞：`8*90*8100 = 5.83M` 参数占总模型 92%。
换成 V6 的 factored head：

```
from_logits[90] = fc(policy_features → 90)    # 8*90*90 = 64.8K
to_logits[90]   = fc(policy_features → 90)    # 8*90*90 = 64.8K
```

总参数量从 6.32M 降到 **~510K**，训练快 10 倍，泛化好得多。

| 指标 | V7 (full 8100) | V8 (factored) |
|------|---------------|---------------|
| 总参数 | 6.32M | ~510K |
| 策略头参数 | 5.85M | ~130K |
| 每 epoch 耗时 | ~7min | ~40s |
| 已有数据 | 14K→74K→683K | 复用 |

V6 之前就达到 Top-10=33%，和 V7 的 34% 几乎一样——说明 factored head 完全够用。

### 🥉 继续堆数据（不推荐）

证据：
- 14K 数据 → Top-10=35% (V3)
- 74K 数据 → Top-10=34% (V7)
- 683K 数据→ Top-10=34% (V7 batch2)

**数据量涨了 40 倍，指标纹丝不动。** 瓶颈不在数据，在模型容量和参数效率。
