# Tool Calling 简介

Tool Calling 的目标是让大模型不只输出文本，还能选择调用外部函数。模型负责判断需要哪个工具和参数，程序负责真正执行工具，并把结果返回给模型继续生成答案。

典型工具包括：

- 查询本地文件。
- 检索知识库。
- 运行数据库查询。
- 读取日历或待办。
- 调用业务系统 API。

设计工具时要注意权限边界。模型不应该直接拥有无限制的文件和网络访问能力，应用层需要限制可调用工具、校验参数，并记录执行结果。

RAG 和 Tool Calling 可以结合使用。比如用户问一个项目问题时，模型先调用 search 工具检索资料，再基于检索结果回答；如果索引过期，模型还可以请求执行 build 工具重建索引。
